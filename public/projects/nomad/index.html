NomadSpaces

Two-sided marketplace, web + iOS · launch

Role
Product designer, web and iOS
Year
2024
Scope
Marketplace UX · iOS · Web · Design system

Supply and demand on the same map, on the web and on a phone.

A two-sided marketplace fails on the weaker side first. Hosts had to publish a space in minutes from a phone, so the listing flow was designed backwards from the shortest path that still produced a listing worth booking.

Guests see the same map, the same words and the same prices — one version of the truth for both sides. The iOS app shares the design system with the web, not merely the palette.
